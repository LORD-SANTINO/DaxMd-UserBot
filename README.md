# 🤖 DAX-MD – Your All-in-One Telegram Userbot

**DAX-MD** is a powerful Telegram userbot that logs into your personal account and automates AI replies, scheduled messages, group management, media downloads, broadcasts, and much more – all controllable via a sleek Mini App.

## ✨ Features
- 🧠 **AI Auto‑Reply** – GPT‑4 / DeepSeek powered
- 📢 **Broadcast Hub** – Send messages to all your chats
- 👥 **Group Management** – Kick, ban, mute, promote, …
- 📅 **Scheduled Messages** – Set reminders & announcements
- 🎥 **Social Media Downloader** – YouTube, TikTok, Facebook, Instagram
- 🛡️ **Anti‑Delete / Anti‑Link**
- 💬 **Mini App** – Full control panel inside Telegram
- 💰 **Affiliate Program** – Earn stars by inviting friends
- … and 100+ commands!

## 🚀 Quick Start

1. Open [@DAXMDrobot](https://t.me/DAXMDrobot) and send `/start`
2. Enter your phone number (with country code)
3. Verify with the code (add spaces between digits!)
4. Done! Your userbot is online.

Use `/myai` to open the Mini App for advanced settings.
